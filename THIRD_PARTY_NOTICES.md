# Third-party notices and release scope

This work builds on **PAMFN: Multimodal Action Quality Assessment**, Ling-An Zeng and Wei-Shi Zheng, IEEE Transactions on Image Processing (2024), repository <https://github.com/qinghuannn/PAMFN>. Author names follow the citation in the preserved upstream README.

The upstream MIT license and copyright notice (`Copyright (c) 2024 qinghuan`) are preserved verbatim at `backbone_reference/LICENSE` and inside the original trainer bundles. Preserve these notices when redistributing substantial upstream code. See upstream files for any additional notices and citations.

This packaging step does not invent an author list, paper title, DOI, or license grant for newly authored contributions. The authors should choose and document the release license before calling the complete new repository “open-source”. Third-party data/features/pretrained checkpoints are not distributed here and may have separate usage terms.

The included original bundles preserve historical Git identities and source defaults. No outer working repository history, credentials, user runtime environment, downloaded dataset or trained checkpoint is intentionally included. Exact reproduction has external prerequisites described in `docs/REPRODUCE.md`.
